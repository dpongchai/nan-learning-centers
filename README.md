# ศูนย์การเรียนรู้เมืองน่าน (Nan Learning Centers)

เว็บไซต์แผนที่รวมศูนย์การเรียนรู้ด้านเกษตร ป่าชุมชน ภูมิปัญญา และอาชีพ ทั่วจังหวัดน่าน
ค้นหา กรองตามหมวด อำเภอ และศูนย์ที่มีหลักสูตรได้ รองรับภาษาไทยและอังกฤษ ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ

ข้อมูลทั้งหมดอยู่ในไฟล์ Excel ไฟล์เดียว แก้ไฟล์นี้แล้วเว็บไซต์จะอัปเดตเอง ไม่ต้องแก้โค้ด

## โครงสร้างไฟล์

```
├── index.html                      หน้าเว็บ
├── assets/
│   ├── css/style.css               สีและรูปแบบหน้าเว็บ
│   └── js/app.js                   แผนที่ ตัวกรอง และรายการ
├── data/
│   ├── Nan_learning_centers.xlsx   ข้อมูลหลัก (แก้ไขที่ไฟล์นี้)
│   ├── centers.json                สร้างอัตโนมัติจาก Excel (ไม่ต้องแก้เอง)
│   └── nan-boundaries.json         ขอบเขตอำเภอ/ตำบล จังหวัดน่าน
├── scripts/
│   ├── build_data.py               แปลง Excel เป็น JSON และตรวจข้อมูล
│   └── requirements.txt
└── .github/workflows/deploy.yml    สร้างและเผยแพร่เว็บอัตโนมัติ
```

## เผยแพร่ขึ้น GitHub Pages (ครั้งแรก)

1. สร้าง repository ใหม่บน GitHub เช่น `nan-learning-centers` (เลือก Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ลากวางในหน้า repository ได้เลย หรือใช้ `git push`)
   ให้ `index.html` อยู่ชั้นบนสุดของ repository
3. ไปที่ **Settings → Pages** ในช่อง **Source** เลือก **GitHub Actions**
4. ไปที่แท็บ **Actions** รอให้ workflow "Build and deploy to GitHub Pages" ขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 1 นาที)
5. เว็บไซต์จะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/nan-learning-centers/`

## อัปเดตข้อมูล

1. เปิด `data/Nan_learning_centers.xlsx` แก้ไข เพิ่ม หรือลบแถวในชีต `LearningCenter`
2. อัปโหลดไฟล์ที่แก้แล้วกลับไปที่โฟลเดอร์ `data/` บน GitHub (ชื่อไฟล์ต้องเหมือนเดิม)
3. GitHub จะสร้าง `centers.json` ใหม่และอัปเดตเว็บให้เองภายในประมาณ 1 นาที

ถ้ามีข้อมูลที่น่าสงสัย เช่น พิกัดอยู่นอกจังหวัด หรือพิกัดไม่ตรงกับอำเภอ/ตำบลที่กรอก
จะแสดงเป็นคำเตือนในแท็บ **Actions** (เปิด workflow ล่าสุด → ขั้นตอน *Convert Excel to JSON*) แต่เว็บยังอัปเดตตามปกติ

### คอลัมน์ในไฟล์ Excel

| คอลัมน์ | จำเป็น | ความหมาย |
|---|---|---|
| Code | ✔ | รหัสศูนย์ ห้ามซ้ำ เช่น C30 ใช้เป็นลิงก์ตรงไปยังศูนย์ (`.../#C30`) |
| Name_TH / Name_EN | ✔ / – | ชื่อไทย / อังกฤษ |
| Category, theme_key | ✔ | ชื่อหมวด และรหัสหมวด: `farm` `forest` `bee` `coffee` `community` `academic` `craft` |
| District_TH, Sub-district_TH (+ _EN) | – | อำเภอ ตำบล |
| lat, lng | ✔ | พิกัด (ถ้าเว้นว่าง ศูนย์จะอยู่ในรายการ "ยังไม่มีที่ตั้ง") |
| Link | – | ลิงก์ Google Maps ใช้กับปุ่ม "เปิดใน Google Maps" |
| Description_TH / Description_EN | – | คำอธิบาย (ถ้าไม่มีภาษาไทย จะใช้คอลัมน์ Note แทน) |
| มีหลักสูตร | – | `มี` `ไม่มี` `กำลังทำ` `ไม่ทราบ` |
| ชื่อหลักสูตร | – | ชื่อหลักสูตร หรือใส่ลิงก์ (https://…) จะแสดงเป็นปุ่ม "ข้อมูลเพิ่มเติม" |
| เบอร์โทร, LINE / Facebook, เวลาเปิด, ต้องจองก่อน, ค่าใช้จ่าย | – | แสดงในหน้าต่างรายละเอียดเมื่อมีข้อมูล |
| ลิงก์รูปภาพ | – | ลิงก์รูป (https://… ที่เป็นไฟล์ภาพ) |
| หมายเหตุการเข้าชม | – | แสดงเป็นกล่องเตือนสีเหลือง |

การเพิ่มหมวดใหม่: ใส่ `theme_key` ใหม่ใน Excel แล้วเพิ่มสีใน `THEME_COLORS` ที่ `scripts/build_data.py`
(ถ้าไม่เพิ่ม หมุดจะเป็นสีเทา)

## ดูตัวอย่างในเครื่อง

เปิด `index.html` ด้วยการดับเบิลคลิกโดยตรงจะโหลดข้อมูลไม่ได้ ให้เปิดผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ:

```bash
pip install openpyxl
python scripts/build_data.py     # สร้าง data/centers.json จาก Excel
python -m http.server 8000       # แล้วเปิด http://localhost:8000
```
